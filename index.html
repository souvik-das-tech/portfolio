How I Engineer

        
Domain expertise over framework loyalty. Languages and frameworks are tools; I pick the
          one that fits the problem.

      


      

        


          

            

              

              
Domain First

              
Deep GIS knowledge: projections, raster and vector, tiling, 3D Tiles, point clouds, PostGIS and OGC services. The hard part of a GIS project is the domain, not the syntax.

            

          

          

            

              

              
Stack-Agnostic

              
Production mobile in Flutter, and the same app ideas rebuilt natively in Kotlin + Jetpack Compose. TypeScript at work, Go and Python in open source. The fundamentals carry over.

            

          

          

            

              

              
System Design in Practice

              
NX monorepo micro-apps, per-app database isolation, Kafka streaming, HAProxy load balancing, object storage migration and 100GB upload pipelines.

            

          

          

            

              

              
Right Tool, Right Time

              
Knowing when microservices pay off (independent scaling, team boundaries, fault isolation) and when a modular monolith is the better call. The same thinking applies to languages and databases.

            

          

          

            

              

              
Security Mindset

              
Hands-on VAPT remediation across auth, input validation, headers, access control and infrastructure config, so security is designed in, not bolted on.

            

          

          

            

              

              
Experiment & Learn

              
I learn something new every day and love building experiments to test ideas before they reach production. My open-source projects started that way.
